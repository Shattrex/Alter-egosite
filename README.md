# Alanto AI - Vintage Comic Style Site

A stylish website for Alanto AI built with a vintage comic book aesthetic, featuring cream, brown, and orange color palette.

## Features

- Vintage comic book inspired design with custom styling
- Smooth loading animations and transitions
- Responsive layout for all devices
- Streamlined header with optimized navigation
- Integrated contact form with webhook functionality

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- Shadcn UI Components

## Sections

- AI Shadow - Clone voice, persona, and expertise
- AI Alter Ego Caller - For automated calling with your voice
- AI Alter Ego Seller - For 24/7 digital sales presence
- Contact Form - Connected to webhook for lead capture

## Deployment

The site is built with Vite and can be easily deployed to any static hosting service.

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
